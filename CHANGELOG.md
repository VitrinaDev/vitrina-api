# Changelog

Versions track the platform release they describe. A release can skip the SDK if
its publish fails, so the registry is the list: `npm view @vitrina/api versions`.

## 11.2.0

First published version. Typed client over the published OpenAPI projection,
typed errors from the catalogue, cursor pagination helper, `Idempotency-Key`
support, webhook signature verification and `event.fetch()`.

Published by hand from the monorepo, before this repository existed, so it
carries no provenance attestation. Every version from here on does.
